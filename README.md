# VT Meal Plan Helper

A Virginia Tech dining plan recommendation tool built as a personal project.

## What It Does

Users can choose between dining hall plans and multiple food options.

For multiple food options, users enter their approximate daily dining spending. The website estimates semester spending and recommends a dining plan based on that amount.

## Features

- View Virginia Tech dining plan options
- Compare Unlimited and Unlimited Plus
- Compare Maroon and Maroon Plus
- Enter approximate daily spending
- Receive a recommended dining plan
- View estimated semester spending

## Technologies

- Java
- HTML
- CSS
- JavaScript

## Development

The recommendation logic was first prototyped in Java and then implemented in JavaScript for the web version.
